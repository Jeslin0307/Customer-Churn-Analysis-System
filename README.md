# Customer Churn Analysis System

## Project Overview

Customer Churn Analysis System is a Data Analytics project that focuses on understanding customer behavior and identifying factors that influence customer churn.
Since real-world customer data is often unavailable due to privacy concerns, this project uses a synthetic dataset containing 100,000 customer records.
The project performs Exploratory Data Analysis (EDA) to discover patterns, trends, and relationships between customer attributes and churn behavior through statistical analysis and visualizations.

**Source:** Kaggle
